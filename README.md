# Max Farren

Tesista del doble grado de Ingeniería Civil Industrial y Magíster en Data Science en la
Universidad de Chile. Construyo
software con modelos de lenguaje que se pueden verificar: que la IA razone y que el código haga
cumplir lo que se puede medir.

**Hoy.** Fundé una empresa de software para digitalizar pymes. Su primer producto es un CRM para
consultoras de innovación, incubadoras y universidades, y lo desarrollo de punta a punta: panel
web, modelo de datos, generación de informes con LLM en la que cada afirmación lleva su fuente,
seguridad y despliegue en la nube.

**Antes.** Automatización con IA en una agencia de marketing digital (Dominant Media), machine
learning y optimización de procesos en una consultora de innovación (Zenit), ingeniería y
análisis de datos en Localshop.
