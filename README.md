Ingeniero Civil Industrial y Magíster en Data Science (Universidad de Chile). Construyo software

que se puede medir.

  ponerla a trabajar con resultados que se puedan revisar.

  despliegue en la nube.
- **Digitalización de empresas**: llevar procesos de planillas y correos a sistemas que se usan

**Hoy.** Cofundador de [valiu](https://valiu.cl), con distintas líneas de negocio.
